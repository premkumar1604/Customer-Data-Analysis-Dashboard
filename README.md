Customer Data Analysis Dashboard
📊 Project Overview

This project is an interactive Customer Data Analysis Dashboard built using Microsoft Power BI. The dashboard analyzes customer purchasing behavior, revenue, product categories, payment methods, shopping malls, age groups, and gender to generate meaningful business insights.

The project demonstrates the use of data visualization, DAX measures, customer segmentation, and interactive dashboard design to transform raw customer transaction data into actionable insights.

🎯 Objectives
Analyze overall customer purchasing behavior.
Understand customer distribution by gender and age group.
Analyze revenue generated across different customer segments.
Compare product categories and payment methods.
Identify shopping malls with different transaction volumes.
Analyze quantity purchased across customer segments.
Present key business KPIs through an interactive Power BI dashboard.

The dashboard uses calculated measures such as:

Revenue
Sum_Quantity

These measures are used to calculate and visualize important business metrics across different customer segments and transaction dimensions.

💡 Business Insights

The dashboard enables businesses to identify:

Which customer segments contribute most to revenue.
Differences in purchasing behavior between male and female customers.
Which age groups generate higher revenue and transaction volumes.
Customer preferences across different payment methods.
Product categories with higher purchase quantities.
Shopping malls with higher transaction activity.
Relationships between product categories, customer demographics, and payment methods.
